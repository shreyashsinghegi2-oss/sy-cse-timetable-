# SY CSE Timetable

A single-page class timetable for SY CSE students that answers the two questions you actually have
between lectures: **what is on now, and what is next?**

## Features

- **Live clock** with the current date
- **"On now" and "Next" cards** with countdowns to the end of the current class and the start of the next one
- **Day tabs** (Monday–Saturday) to browse the full week
- **Class details**: tap a lecture to see time, room, faculty and session type
- **Section switcher** for different divisions
- **Built-in editor** to update the schedule, save it in the browser, or reset it to the default
- **Timetable image upload** to keep the official timetable photo alongside the interactive view

## Tech

One self-contained `index.html`: HTML, CSS and vanilla JavaScript. No build step, no dependencies,
and no server. Edits are stored locally in the browser.

## Run it

Open `index.html` in any browser, or host the repository with GitHub Pages or Vercel as a static site.
