ABOUT THIS PACKAGE
------------------
This is a fully self-contained, static web page for the
National Conference on Aerospace & Defence Technologies 2026
(NCADT 2026), organized by the Department of Space Engineering,
Ajeenkya DY Patil University, Pune, in collaboration with the
Aeronautical Society of India (AeSI).

HOW TO OPEN
-----------
1. Extract this folder to any location on your computer or server.
2. Open "index.html" in any modern web browser
   (Chrome, Edge, Firefox, Safari).
   Simply double-click the file — NO server or installation needed.

FOLDER STRUCTURE
----------------
conference-page/
  index.html          ← Main page (open this)
  css/
    styles.css        ← All animations and custom styles
  js/
    stars.js          ← Starfield background generator
  images/
    adypu-logo.png    ← University logo
  assets/             ← Reserved for any future assets
  README.txt          ← This file

HOSTING ON A WEB SERVER (College IT Team)
-----------------------------------------
1. Upload the entire "conference-page/" folder to your web server.
2. Point your domain or subdomain to the folder.
3. Make sure all paths remain relative (they already are).
4. The page works from any HTTP/HTTPS server — no backend needed.

EXTERNAL DEPENDENCIES (requires internet)
------------------------------------------
- Tailwind CSS CDN (cdn.tailwindcss.com)
- Google Fonts – Inter (fonts.googleapis.com)

If internet access is NOT available on your server:
- Download Tailwind CSS standalone from https://tailwindcss.com/blog/standalone-cli
  and replace the <script src="https://cdn.tailwindcss.com"> tag in index.html
  with a local copy.
- The Inter font will fall back to the system sans-serif font automatically.
